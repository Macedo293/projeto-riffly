# Mapa de Funcionalidades — MVP

Este documento define o que cada lado da plataforma — Banda e Produtor — consegue fazer na primeira versão do Riffly. O objetivo do MVP é validar o encontro entre os dois lados (descoberta + primeiro contato), sem ainda incluir funcionalidades de gestão mais avançadas, como pagamento dentro do app ou agendamento automático de sessões.

## Funcionalidades comuns aos dois lados

Antes de separar por perfil, algumas funcionalidades são compartilhadas:

- Cadastro e login (e-mail ou redes sociais)
- Escolha do tipo de perfil no momento do cadastro: Banda ou Produtor
- Edição de perfil próprio
- Sistema de mensagens simples para primeiro contato entre os dois lados
- Notificações (novo interesse, nova mensagem)

## Funcionalidades do lado Banda

| Funcionalidade | Descrição |
|---|---|
| Navegar pelo feed de produtores | Visualizar cards de produtores em formato de lista/feed deslizável |
| Filtrar produtores | Filtrar por gênero musical, faixa de preço, localização e avaliação |
| Ouvir amostras de portfólio | Tocar trechos de áudio de trabalhos anteriores do produtor direto no card, sem sair da tela |
| Visualizar perfil completo do produtor | Ver portfólio completo, avaliações de outras bandas, faixa de preço e disponibilidade |
| Favoritar produtores | Salvar produtores de interesse para comparar depois |
| Iniciar contato | Enviar mensagem inicial para um produtor a partir do perfil dele |
| Avaliar produtor | Após o serviço concluído, deixar avaliação e nota para o produtor (alimenta a confiança de outras bandas) |

## Funcionalidades do lado Produtor

| Funcionalidade | Descrição |
|---|---|
| Criar perfil profissional | Definir nome do estúdio, gêneros musicais que domina, descrição |
| Subir portfólio | Upload de trechos de áudio de produções anteriores |
| Definir faixa de preço | Indicar valor aproximado do serviço, podendo variar por tipo de pacote |
| Definir disponibilidade | Indicar status simples de agenda (disponível agora, agenda cheia, sob consulta) |
| Visualizar interesse recebido | Ver quais bandas visualizaram o perfil ou favoritaram o estúdio |
| Responder mensagens | Receber e responder o primeiro contato de uma banda interessada |
| Visualizar avaliações recebidas | Ver feedback deixado por bandas que já trabalharam com ele |

## Fora do escopo do MVP

Para deixar claro o que conscientemente não entra nesta primeira versão:

- Pagamento dentro do aplicativo
- Agendamento automático de sessões via calendário integrado
- Chat com recursos avançados (chamada de voz/vídeo, compartilhamento de arquivos grandes)
- Sistema de contratos ou assinatura digital

Essas funcionalidades ficam mapeadas como possíveis evoluções futuras, mas não são necessárias para validar a proposta de valor central do produto: conectar banda e produtor de forma mais eficiente do que o processo informal atual.
